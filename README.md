# dupdetector

A production-ready .NET CLI tool that detects code duplication in C# codebases and outputs a structured, LLM-friendly report for automated refactoring.

## Overview

`dupdetector` analyzes C# source files by parsing them with Roslyn, normalizing the syntax tree (stripping identifiers and literal values), and grouping structurally equivalent blocks using hash matching and Jaccard similarity. The default output is a deterministic YAML report; JSON and static HTML are also supported.

## Key Features

- **Exact duplicate detection** â identifies copy-pasted code blocks using SHA-256 hashing of normalized syntax trees
- **Near-duplicate detection** â groups structurally similar code using Jaccard token-set similarity
- **Multi-level duplication scoring** â normalized 0â100 scores at cluster, file, project, and solution level
- **Solution filter support** â loads `.slnx` files and analyzes only the included subset of projects
- **Multiple output formats** â YAML (default), JSON, and interactive static HTML report
- **Zero non-Microsoft dependencies** â built exclusively on Roslyn and MSBuild APIs
- **Multiple input modes** â accepts `.sln`, `.slnx`, `.csproj`, or a plain directory
- **LLM-optimized output** â deterministic YAML/JSON with normalized snippets and raw source for tool or LLM consumption
- **Configurable thresholds** â tune minimum line count, similarity threshold, and exclusion globs
- **Auto-generated file skipping** â ignores `.Designer.cs`, `.g.cs`, `<auto-generated>` files by default

## Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

### First-time Setup

Clone the repository and restore dependencies:

```bash
git clone https://github.com/jefernn-ms/dupdetector.git
cd dupdetector
dotnet restore
```

### Build

```bash
dotnet build
```

### Test

Run the full test suite (5000+ tests):

```bash
dotnet test
```

Run with verbose output:

```bash
dotnet test --logger "console;verbosity=detailed"
```

### Install as a Global Tool

Pack and install from source:

```bash
dotnet pack src/DupDetector/DupDetector.csproj -c Release -o ./nupkg
dotnet tool install -g DupDetector --add-source ./nupkg
```

### Usage

```bash
dupdetector <path> [options]

Options:
  --solution <path>        Solution/project/directory path (alias for positional arg)
  --min-lines <int>        Minimum lines to consider a block (default: 5)
  --similarity <0-1>       Jaccard similarity threshold (default: 0.85)
  --format yaml|json|html  Output format (default: yaml)
  --output <path>          Write output to a file instead of stdout
  --exclude <glob>         Glob pattern to exclude (repeatable)
  --include-generated      Include auto-generated files (default: false)
```

#### Examples

Scan a solution (YAML to stdout):
```bash
dupdetector MyApp.sln
```

Scan using a solution filter (.slnx):
```bash
dupdetector MyApp.slnx --min-lines 10
```

Generate an interactive HTML report:
```bash
dupdetector ./src --format html --output report.html
```

Scan a directory and exclude tests, output JSON:
```bash
dupdetector ./src --exclude "**/*.Tests.cs" --similarity 0.90 --format json
```

Use `--solution` flag explicitly:
```bash
dupdetector --solution MyApp.sln --format yaml --output dup-report.yaml
```

## Duplication Scoring

### How the Score is Calculated

Scores are computed at four levels:

| Level    | Formula                                                                 | Range  |
|----------|-------------------------------------------------------------------------|--------|
| Cluster  | `min(100, (min(lines,50) Ã min(occ,10) Ã min(spread,5)) / 25)` | 0â100 |
| File     | `(duplicate lines in file) / (total lines in file) Ã 100`          | 0â100 |
| Project  | `(duplicate lines in project) / (total lines in project) Ã 100`    | 0â100 |
| Solution | `(total duplicate lines) / (total lines) Ã 100`                    | 0â100 |

**Cluster score** factors:
- **Lines** â size of the duplicated block (capped at 50 for normalization)
- **Occurrences** â how many times the block appears (capped at 10)
- **Spread** â number of distinct files affected (capped at 5)

### Score Interpretation

| Score   | Label    | Meaning                                              |
|---------|----------|------------------------------------------------------|
| 0â10   | Low      | Minimal duplication. Codebase is healthy.            |
| 10â30  | Medium   | Moderate duplication. Consider extracting helpers.   |
| 30â60  | High     | Significant duplication. Prioritize refactoring.     |
| 60â100 | Critical | Severe duplication. Immediate action recommended.    |

### Prioritizing Refactoring with the Results

1. **Sort clusters by `duplicationScore` descending** â the top entries are the highest-value refactoring targets.
2. **Look at `spread`** â blocks spread across many files are strong candidates for shared utility extraction.
3. **Check `fileScores`** â files with a high score are duplication hotspots and may benefit from a full review.
4. **Use `projectScores`** â identify which projects contribute most to solution-level duplication.
5. **Read `normalizedSnippet`** â the normalized form highlights the structural pattern being duplicated.

### HTML

The `--format html` option generates a self-contained, interactive report with:
- Summary cards (score, clusters, lines, files)
- Score interpretation guide
- Bar charts for the top file and project hotspots
- Sortable and filterable cluster table (by score, lines, occurrences, spread)
- Tree view (file â cluster â instances with code snippets)
- Search and navigation anchors

```bash
dupdetector ./src --format html --output report.html
```

## CI Integration

Add a step to your GitHub Actions workflow:

```yaml
- name: Detect Code Duplication
  run: |
    dotnet tool install -g DupDetector --add-source ./nupkg
    dupdetector ./src --format yaml --output dup-report.yaml
    SCORE=$(python3 -c "import re,sys; m=re.search(r'duplicationScore: (\d+\.\d+)',open('dup-report.yaml').read()); print(m.group(1) if m else '0')")
    echo "Solution duplication score: $SCORE"
    # Fail if score exceeds threshold:
    # python3 -c "import sys; sys.exit(1 if float('$SCORE') > 30 else 0)"

- name: Upload Duplication Report
  uses: actions/upload-artifact@v4
  with:
    name: dup-report
    path: dup-report.yaml
```
