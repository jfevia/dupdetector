# dupdetector

A production-ready .NET CLI tool that detects code duplication in C# codebases and outputs a structured, LLM-friendly report for automated refactoring.

## Overview

`dupdetector` analyzes C# source files by parsing them with Roslyn, normalizing the syntax tree (stripping identifiers and literal values), and grouping structurally equivalent blocks using hash matching and Jaccard similarity. The output is a deterministic JSON or YAML report optimized for consumption by large language models and CI pipelines.

## Key Features

- **Exact duplicate detection** – identifies copy-pasted code blocks using SHA-256 hashing of normalized syntax trees
- **Near-duplicate detection** – groups structurally similar code using Jaccard token-set similarity
- **Zero non-Microsoft dependencies** – built exclusively on Roslyn and MSBuild APIs
- **Multiple input modes** – accepts `.sln`, `.csproj`, or a plain directory
- **LLM-optimized output** – deterministic JSON/YAML with normalized snippets and raw source
- **Configurable thresholds** – tune minimum line count, similarity threshold, and exclusion globs
- **Auto-generated file skipping** – ignores `.Designer.cs`, `.g.cs`, `<auto-generated>` files by default
- **Parallel-friendly** – designed to scale to 1M+ LOC codebases

## Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

### First-time Setup

Clone the repository and restore dependencies:

```bash
git clone https://github.com/jefernn-ms/dupdetector.git
cd dupdetector
dotnet restore
```

### Build

```bash
dotnet build
```

### Test

Run the full test suite (5000+ tests):

```bash
dotnet test
```

Run with verbose output:

```bash
dotnet test --logger "console;verbosity=detailed"
```

### Install as a Global Tool

Pack and install from source:

```bash
dotnet pack src/DupDetector/DupDetector.csproj -c Release -o ./nupkg
dotnet tool install -g DupDetector --add-source ./nupkg
```

### Usage

```bash
dupdetector <path> [options]

Options:
  --min-lines <int>      Minimum lines to consider a block (default: 5)
  --similarity <0-1>     Jaccard similarity threshold (default: 0.85)
  --format json|yaml     Output format (default: json)
  --exclude <glob>       Glob pattern to exclude (repeatable)
  --include-generated    Include auto-generated files (default: false)
```

#### Examples

Scan a solution:
```bash
dupdetector MyApp.sln --min-lines 10 --format json
```

Scan a directory and exclude tests:
```bash
dupdetector ./src --exclude "**/*.Tests.cs" --similarity 0.90
```

Integrate in CI (non-zero exit on any duplicates):
```bash
dupdetector ./src --format json | jq '.summary.totalDuplicates'
```

### CI Integration

Add a step to your GitHub Actions workflow:

```yaml
- name: Detect Code Duplication
  run: |
    dotnet tool install -g DupDetector --add-source ./nupkg
    dupdetector ./src --format json --min-lines 10 > dup-report.json
    COUNT=$(jq '.summary.totalDuplicates' dup-report.json)
    echo "Duplicate clusters found: $COUNT"
    # Fail if threshold exceeded:
    # [ "$COUNT" -lt 10 ] || exit 1

- name: Upload Duplication Report
  uses: actions/upload-artifact@v4
  with:
    name: dup-report
    path: dup-report.json
```
